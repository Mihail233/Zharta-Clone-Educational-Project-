# Zharta Clone (Educational Project)
Zharta Clone — учебный проект, представляющий собой упрощённую копию старой версии сайта оригинальной платформы Zharta. Разработан с целью изучения архитектуры приложений, практики программирования и освоения современных технологий. Не предназначен для коммерческого использования и создан исключительно в образовательных целях.
